About Me

안녕하세요! 복잡한 데이터를 사용자가 이해하기 쉬운 화면으로 바꾸는 것과 직관적인 사용자 경험을 가장 중요하게 생각하는 프론트엔드 엔지니어입니다.

금융 데이터 분석부터 AI/ML 모델링, 그리고 프론트엔드 개발까지 폭넓은 경험을 보유하고 있습니다. 특히 실시간 데이터, 다수의 상태 변화, 빈번한 사용자 인터랙션 환경에서 UI가 예측 가능하게 동작하도록 상태 구조와 렌더링 흐름을 설계해왔습니다.

Python, TensorFlow, PyTorch를 활용한 모델 개발 경험과 React / TypeScript 기반 대시보드 및 운영(백오피스) UI 구현 경험이 있습니다.

Frontend Focus

• 예측 가능한 UX: 사용자가 클릭/입력했을 때 기대하는 반응이 나오도록 흐름을 먼저 정의합니다.
• 상태 설계: Loading / Empty / Error / Retry 상태를 표준화해 화면이 멈추지 않게 만듭니다.
• 테이블/리스트 UX: 검색·필터·정렬·체크박스 일괄 처리·무한스크롤 등 운영용 UI를 안정적으로 구현합니다.
• 유지보수성: 공통 컴포넌트화(TableLayout, Header/Row, Badge 등)로 재사용성과 일관성을 높입니다.

02

HomeProtector - AI 전세사기 탐지

XGBoost + SHAP + Gemini API 결합으로 전세 사기 위험 예측 및 자연어 설명 생성. 예측 정확도 12% 향상, 토큰 비용 35% 절감. React 기반 통합 정보 플랫폼 구축.

Frontend Contribution
  • 전세사기 예방을 위해 필요한 등기부등본·공공 데이터를 AI 분석 결과 기반으로 직관적으로 이해할 수 있는 UI로 재구성
  • React 환경에서 Kakao 로그인 시 StrictMode로 인한 useEffect 중복 실행을 고려해 개발/운영 환경 차이를 반영한 로그인 로직으로 안정화
  • 라우팅 전환 및 새로고침 시에도 입력 흐름이 끊기지 않도록 Zustand + localStorage를 연동해 사용자 입력 상태를 유지
  • 입력 → 분석 → 결과의 3단계 UX를 구성하고, 로딩·오류·재시도·근거 노출을 포함한 신뢰 UX 패턴 적용
