About Me

안녕하세요! 사용자가 기대한 대로 반응하는 화면을 만드는 프론트엔드 개발자 김민재입니다.

저는 기능을 “구현”하는 것에서 끝내지 않고, 입력 → 처리 → 피드백 → 완료 흐름이 끊기지 않도록 인터랙션과 상태 변화를 설계합니다. 폼 검증, 로딩/에러/빈 상태, 라우팅 전환, 테이블/리스트 UX처럼 실서비스에서 자주 깨지는 지점을 기준으로 UI를 안정적으로 만듭니다.

또한 데이터 분석 경험을 바탕으로 지표 기반 개선과 설득 가능한 UI 결정을 선호합니다. (필요한 경우에만 LLM/RAG 같은 기술을 제품 문제 해결의 수단으로 연결합니다.)

Frontend Highlights

아래는 실제 프로젝트에서 반복적으로 해결해온 프론트엔드 핵심 영역입니다.

• 테이블 UX: 검색/필터/정렬, 체크박스 일괄 처리, Sticky Header, Infinite Scroll
• 상태 표준화: Loading / Empty / Error / Retry / Toast로 “멈추지 않는 흐름” 설계
• API 연동: React Query 기반 캐시/동기화, 낙관적 업데이트, 실패 복구 패턴 적용
• 컴포넌트 설계: 공통 레이아웃/배지/테이블 컴포넌트화로 재사용성과 유지보수성 강화
• 신뢰 UX: 결과 근거 노출, 단계형 화면(입력→분석→결과), 사용자 불안 요소 제거
